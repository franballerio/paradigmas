# Object Oriented Programming
(Java, Python, Ruby, .NET)

Un objeto es una entidad que tiene:
- **Identidad** que lo diferencia de los demas
- **Estado** que almacena datos del mismo
- **Comportamiento** para relacionarse con otros
Los objetos interactuan entre si mediante **mensajes** 

Es mucho muy importante que el diseno del sistema sea coherente y basado en el comportamiento esperado del sistema. Y que las piezas de codigo representen el problema de forma organica.

## UML (Unified Modeling Language)
Usaremos estas convenciones para describir el codigo de una manera mas humana.
- Diagrama de clases
- Diagrama de secuencias

### Diagrama de clases
Captura la estructura de un sistema mostrando clases, interfaces, atributos, metodos y relaciones.
Debe capturar y resumir las ideas principales del sistema.
